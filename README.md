# nguyen-tien-thanh/tap

Homebrew tap for [StatBar](https://github.com/nguyen-tien-thanh/statbar), a lightweight macOS menu bar system monitor.

```sh
brew install --cask nguyen-tien-thanh/tap/statbar
```

Update: StatBar updates itself from the popover, or `brew upgrade --cask statbar`.
Uninstall: `brew uninstall --cask statbar` (add `--zap` to also remove settings and the Touch ID helper).

The cask is bumped automatically by StatBar's release workflow.
